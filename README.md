# Dataset Infrastructure — Abundance Federation

This repository contains dataset pilots and supporting infrastructure for the Abundance Federation.

## Structure

- `pilot-01/` — Irish weed identification micro-pilot
- `shared/` — reusable scripts, templates, and tools
- `docs/` — documentation and design notes

## Purpose

To test whether structured volunteer workflows can produce high-quality datasets
for AI systems in areas such as agriculture, energy, and environment.

## Status

Initial setup — Pilot 01 in development.
